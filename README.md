# 📱 note.com スマホ最適化エディタ

> note.com（ノート）のスマホ表示で発生しやすい**「閉じカッコ（」）の孤立改行」**や**「引用枠（>）の意図しない分割」**を自動で補正・プレビュー確認できる軽量Webアプリケーション（PWA対応）です。

---

## ✨ 主な機能

1. **孤立改行（ orphan ）の自動補正**
   * 「…？」や「…！」の直後にくる閉じカッコ `」` が、スマホ画面の横幅によって次の行へポツンと落ちてしまう表示崩れを防止します。
2. **引用枠（`>`）の結合保護**
   * `>` マークが連続する引用ブロックを、途切れさせることなく1つの綺麗な枠として結合表示します。
3. **リアルタイム・デバイスプレビュー**
   * 入力した文章がスマホ（横幅375px）やPCでどう表示されるかを、noteのフォント・行間を再現した環境で即座に確認できます。
4. **PWA（ホーム画面追加）対応**
   * スマホのホーム画面に追加することで、アドレスバーのないスタンドアロンアプリとしてネイティブ感覚で利用可能です。

---

## 📱 スマホアプリとしての追加方法（PWA）

### iPhone (Safari) の場合
1. Safariで公開URLを開く
2. 画面下部の **「共有ボタン（□に↑）」** をタップ
3. **「ホーム画面に追加」** を選択

### Android (Chrome) の場合
1. Chromeで公開URLを開く
2. 画面右上の **「3点リーダー（⋮）」** をタップ
3. **「ホーム画面に追加」** または **「アプリをインストール」** を選択

---

## 🛠 使い方

1. 左側の入力欄に、noteに投稿したい原稿（Markdown対応）を貼り付けます。
2. **「⚡️ 最適化して変換」** ボタンを押します。
3. 右側のプレビュー画面でレイアウトを確認します。
4. **「📋 結果をコピー」** ボタンでテキストをコピーし、noteのエディタに貼り付けて投稿します。
