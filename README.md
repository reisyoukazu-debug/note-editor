# 📱 Note Mobile Formatter (note.com スマホ最適化エディタ)

note.comのモバイル表示における「鍵カッコ `」` の孤立改行」や「引用ブロック `>` の不完全な分断」を完璧に解消し、スマホで読みやすくするための専用Webアプリ（PWA対応）です。

## ✨ 主な機能と特徴
1. **句読点オート改行＆カッコ内保護**:
   - 句点（`。`）や読点（`、`）での自動改行をトグルで切り替え可能。
   - 会話文などの鍵カッコ（`「〜」`）内にある句読点は誤って改行されないよう自動で保護します。
2. **閉じカッコの孤立防止**:
   - `「...？」` や `...！」` などの文末で、閉じカッコ `」` だけが次の行へ落ちてしまう現象を防ぎます。
3. **引用ブロック（`>`）の一体化**:
   - 連続する引用行が途中で分断されず、1つの綺麗なグレー枠として綺麗に結合されます。
4. **Markdown記号の完全サポート**:
   - `## 見出し` / `### 小見出し`
   - `* 箇条書き` / `- リスト`
   - `---` 区切り線
   - `**太字**`
5. **表示デバイスの切り替え**:
   - プレビュー画面で「スマホ（375px）」と「PC」の表示を瞬時に切り替えて確認できます。
6. **PWA（スマホアプリ化）対応**:
   - スマホのホーム画面に追加することで、ネイティブアプリ感覚で全画面起動できます。

## 📲 使い方
1. ブラウザでアプリを開き、入力欄にnoteの下書きを貼り付けます。
2. 必要に応じて「⚙️ 整形ルール設定」のチェックを切り替えます。
3. プレビューで表示崩れがないか確認します。
4. 「📋 結果をコピー」を押し、noteの編集画面にそのまま貼り付けます。
